# Мифтах — техническое задание, этап 1 (MVP на GitHub Pages)

Режим: публичный прототип. UX и визуал важнее тестов. Методика: 01-kuzmin-method.md. Технические факты: 02-research.md.

## Цель
Студент с нуля заходит на сайт, проходит вводный юнит и юниты 1–4. Он печатает прописи,
повторяет буквы и слова по интервальной схеме и видит свой стрик. После первого захода всё работает офлайн.

## Стек
- Next.js (App Router, `output: 'export'`) + TypeScript + Tailwind 4 + Base UI + Lucide.
- Dexie 4 (IndexedDB): прогресс, карточки, журнал занятий.
- ts-fsrs 5: планирование повторений. Перед кодом сверить API через Context7.
- PWA: service worker через Serwist или ручной sw.js. Выбрать после проверки совместимости со static export.
- Шрифты: Amiri и Noto Naskh Arabic (OFL), самохостинг.
- Деплой: GitHub Actions на Pages, `basePath` = имя репо.
- Контент: `content/units/*.yaml`, на сборке валидируется схемой (zod) и превращается в JSON.

## Модель данных контента
- **Unit**: id, номер, название, буквы[], грамматические темы[], lessons[].
- **Lesson**: id, тип (letters | reading | grammar | review), шаги[].
- **Step**: теория (markdown + примеры) или упражнение.
- **Exercise**, типы в MVP:
  1. выбор: услышь или увидь, выбери вариант;
  2. буква в позиции: найди начальную, срединную или конечную форму;
  3. сборка слова из букв-плиток;
  4. чтение слога или слова: выбери транскрипцию;
  5. перевод фразы плитками, ар→рус и рус→ар;
  6. ввод транскрипцией с мягким сравнением.
- **Word**: id, арабский с огласовками, транскрипция, перевод, корень, род, юнит появления.
  Лексика юнита использует только буквы, уже пройденные к этому юниту. Скрипт сборки это проверяет.

## Локальные данные (Dexie)
- `progress`: lessonId, статус, точность, дата.
- `cards`: id (буква или слово), состояние FSRS, дата следующего повторения.
- `sessions`: дата, минуты, число упражнений. По ним считаются стрик и тепловая карта.
- `settings`: цель в минутах в день, дни занятий, тема оформления.
- Экспорт и импорт всех данных JSON-файлом в настройках.

## Экраны
1. **Главная, «Сегодня»**: стрик, кольцо дневной цели, одна кнопка «Продолжить»
   (следующий урок или повторение, если накопились карточки).
2. **Карта курса**: юниты по Кузьмину, внутри уроки-кружки, замки на будущих юнитах.
3. **Урок**: полноэкранный, прогресс-бар, мгновенная обратная связь, клавиши 1–4, Enter, Esc.
4. **Повторение**: очередь FSRS, оценки «снова / трудно / хорошо / легко».
5. **Алфавит**: таблица 28 букв в четырёх позициях, клик по букве открывает звук, примеры и кнопку «прописи».
6. **Прописи**: выбор букв или слов, параметры (размер, повторы, серый образец), превью,
   печать через print CSS в A4. PDF получается системной печатью браузера, без библиотек.
7. **Статистика**: тепловая карта, сколько букв и слов выучено.
8. **Настройки**: цель, экспорт и импорт, «скачать всё для офлайна» с размером.

## Аудио
В MVP звучат только буквы и слоги. Записи делаем свои или берём из открытого источника с
подходящей лицензией. edge-tts для публичного продукта не используем, это запрещает лицензия.
Если своих записей нет, кнопка звука скрывается и не ломает урок.

## Вне этапа 1
Словарь, тексты для чтения, говорение, письмо на экране, юниты с 5-го.

## Критерии приёмки (проверяет агент)
1. `npm run dev` поднимает сайт одной командой. `npm run build` делает статику в `out/` без ошибок.
2. Golden path в Playwright: главная → юнит 1 урок 1 → все упражнения → урок засчитан →
   стрик 1 → карточки появились в повторении.
3. После перезагрузки прогресс сохраняется. В офлайне (Playwright offline) главная и
   пройденные уроки открываются.
4. Прописи: превью для 3 букв, печать в PDF даёт A4 без обрезаний (проверка через page.pdf).
5. Арабский текст справа налево, огласовки не наезжают. Проверка скриншотами на 1280, 768 и 360.
6. Скрипт контента падает, если в слове юнита есть непройденная буква.
7. Сборка с `basePath` открывается на GitHub Pages без битых путей.

## Порядок работ
1. Каркас, токены, шрифты, деплой пустой страницы на Pages.
2. Схема контента, валидатор, вводный юнит и юнит 1.
3. Движок урока и шесть типов упражнений.
4. Dexie, FSRS, экран «Сегодня», стрик.
5. Алфавит и прописи с печатью.
6. Юниты 2–4, PWA и офлайн.
7. QA по критериям, скриншоты.
