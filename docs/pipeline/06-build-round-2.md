## Журнал
- [x] 3. Юниты 2–4: юнит 2 (4 урока, 21 слово), юнит 3 (5 уроков, 25 слов), юнит 4 (5 уроков, 24 слова + первые фразы هٰذَا بَيْتٌ, هَلْ/مَا/نَعَمْ). Валидатор: малый алиф перенесён на юнит 4 (в هٰذَا); ة раскрывается в ت+ه, أ/إ/ؤ/ئ в подставку+ء, шадда/танвин с юнита 3; у слов в сборке появилось поле letters. Негативный тест: `مَدِينَة أَب هٰذَا` в юните 2 → ошибки по م ي ن (позже в юните), ه и ء (юнит 3), малому алифу (юнит 4).
- [x] 1. Алфавит `/alphabet/`: 28 букв + хамза в 4 позициях (у хамзы только отдельная), отметка пройденных, карточка (Base UI Dialog): название, звук, как соединяется, реальные формы, пример слова только из пройденных букв, «Прописи для этой буквы», ссылка на урок.
- [x] 2. Прописи `/copybook/`: буквы по одной, по юнитам или «пройденные»; тип листа (4 позиции / слоги / слова юнитов); размер строки; 3/5/8 серых образцов; 0–2 пустых строки; серый образец выключается. Состояние в URL (`?letters=ب,ت&type=forms`). Листы A4 (210×297 мм, @page margin 0, поля 12 мм), без шапки сайта. Базовая линия Amiri меряется в браузере, буквы стоят на линовке. `scripts/e2e-print.mjs`: page.pdf → A4 595×842 pt, число страниц = числу листов, строки и образцы внутри полей, чёрный образец у правого края (RTL). PDF: `screenshots/copybook-forms.pdf`, `copybook-words.pdf`. Поправлено по PDF: огласовки первой строки задевали шапку (отступ 5 мм), серый с прозрачностью в PDF ломал позиции огласовок (сплошной токен `--trace`).
