# 05. Сборка, раунд 1 (шаги 1–4 ТЗ)

Режим: публичный прототип. Статический экспорт Next.js на GitHub Pages, данные пользователя в IndexedDB.
Дизайн-артефактов (03-design / tokens.css) в pipeline нет: токены заданы в этом прогоне по поручению оркестратора («бумажная» светлая + тёмная тема), в одном файле.
