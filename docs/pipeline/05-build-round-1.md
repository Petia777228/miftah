# 05. Сборка, раунд 1 (шаги 1–4 ТЗ)

Режим: публичный прототип. Next.js static export на GitHub Pages, данные ученика в IndexedDB.
Живой сайт: https://petia777228.github.io/miftah/ · Репозиторий: https://github.com/Petia777228/miftah (public)

## Как запустить
`npm install && npm run dev` → http://localhost:3000. `npm run build` → `out/`. `npm run content` — только сборка и проверка контента. `npm run e2e` — golden path (нужен запущенный dev; `BASE_URL=...` для живого сайта).

Actions: checkout@v7, setup-node@v7, configure-pages@v6, upload-pages-artifact@v5, deploy-pages@v5.

## Что сделано
- [x] **1. Каркас.** Токены только в `src/styles/tokens.css` (светлая «бумага» + тёмная, `@theme inline`, тема без мигания через inline-скрипт + зеркало в Dexie). Шрифты самохостингом из google/fonts: Amiri, Noto Naskh Arabic (арабский), Literata (заголовки и транскрипция: в ней есть з̱ с̣ х̣ а̄), Golos Text (UI). Сабсет в WOFF2 (fonttools), `src/app/fonts/OFL.txt`. Арабский всегда `lang="ar" dir="rtl"`, line-height 1.8–2. grep по сырым `#hex` в компонентах чист (hex только в tokens.css и в ассете `icon.svg`).
- [x] **2. Контент.** Схема zod: `src/content/schema.ts`. Сборка `scripts/build-content.ts` (YAML → `src/generated/content.json`, запускается в predev/prebuild). Проверяет: буквы по `content/letters.yaml` (юнит каждой буквы = таблица Кузьмина) **на уровне урока**, огласовочные знаки по `course.yaml` (шадда и танвин только с юнита 3), составные написания (أ = алиф+хамза, ة = та+ха), неизвестные символы, дубли id, непривязанные слова, верный ответ среди неверных. Падает с кодом 1 и сообщением: файл, урок, шаг, строка, какая буква, где она вводится, какие буквы пройдены.
  Контент: вводный юнит (3 урока: звуки, направление письма, огласовки и сукун), юнит 1 (4 урока: даль/заль/алиф, ра/зай, вав, слог и чтение), 13 слов с огласовками, транскрипцией, переводом, корнем. Поле `free` у всех 25 юнитов в `course.yaml`.
  **Проверено намеренной поломкой:** слово `ذَرَّ بَاب` в уроке u1-l1 → «буква ر ещё не пройдена: вводится в уроке u1-l2», «буква ب вводится в юните 2», «знак шадда вводится в юните 3», exit 1. Возврат → зелёная сборка.
  **Важно:** пример из ТЗ `ذَرَّ` в юнит 1 не проходит: шадда по Кузьмину в юните 3. Вместо него `ذَرَا` («развеял»).
- [x] **3. Движок урока.** Полноэкранный, прогресс-бар (Base UI Progress), мгновенная обратная связь в футере, ошибка возвращает упражнение в конец урока, точность по первой попытке. Клавиши: 1–9 варианты/плитки, Backspace, Enter проверить/дальше, Esc → AlertDialog (Base UI). Шесть типов: choice, position (формы строит сборка через татвиль), build (плитки-графемы), read, tiles ar→ru и ru→ar, input (мягкое сравнение: без долгот, латиница, одна опечатка). Аудио: поле `audio` появляется только если файл есть в `public/audio/`, иначе кнопки нет.
- [x] **4. Данные.** Dexie: `progress`, `cards`, `sessions`, `settings`. ts-fsrs 5.4: карточки букв и слов создаются при завершении урока, «Повторение» с превью интервалов на 4 кнопках (1–4, Пробел). «Сегодня»: стрик, полоса 7 дней, кольцо цели (5/10/15/20 мин, Base UI ToggleGroup), одна кнопка «Продолжить» (≥10 карточек → повторение, иначе следующий урок; Enter). Карта курса: 25 юнитов, 2–24 с замком, темами и буквами из методики.
- [x] **Деплой.** Репо `Petia777228/miftah`, Pages source = GitHub Actions (`gh api .../pages build_type=workflow`), `basePath=/miftah` через `NEXT_PUBLIC_BASE_PATH`, `trailingSlash`, `.nojekyll`. Оба прогона Actions зелёные.
