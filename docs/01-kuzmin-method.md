# Методическая модель: Кузьмин С.А. «Учебник арабского языка» (1-й год, Восточная литература, 2001)

Источник: оглавление, с. 376–381 PDF. Используем ТОЛЬКО последовательность и дозировку тем.
Тексты, примеры и упражнения учебника в продукт не копируем.

## Структура
- 24 урока. Вводная «Фонетика» + уроки 1–9 фонетико-графические, с 10-го «Морфология. Синтаксис».
- Буквы вводятся группами по 3–6 вместе с грамматикой: к уроку 4 уже имя, род, именное
  предложение; к уроку 7 первый глагол в прошедшем.
- Каждый урок: новая порция + предложения/текст для чтения. С урока 13: текст + диалог.
- Прописи в оригинале дублируют фонетические упражнения (рукописный насх), это наш модуль 4.

## Что берём в методику Мифтах
1. **Буквы и грамматика параллельно**, не «сначала весь алфавит». Осмысленные фразы на 2–3 неделе.
2. **Урок Кузьмина = юнит** из 4–8 мини-уроков в формате Duolingo.
3. **Глагол рано** (юнит 7), породы после чисел и времён.
4. **Чтение в каждом юните**, диалоги с середины курса.
5. **Прописи рукописного насха** к каждой букве.

## Юниты этапа 1 (MVP)
Вводный + юниты 1–4: буквы групп 1–4, первые имена, род, именное предложение, вопрос.
