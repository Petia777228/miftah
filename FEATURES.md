# UX-фишки Мифтаха (раунд 1)

| Что | Зачем | Как |
|---|---|---|
| Проверка методики на сборке | Слово с непройденной буквой или знаком (шадда, танвин раньше юнита 3) не попадёт к ученику | `scripts/build-content.ts`: буквы из `letters.yaml`, знаки из `course.yaml`, проверка на уровне урока, понятная ошибка с местом и списком пройденных букв |
| Буква в позиции без ручной разметки | Формы букв не надо вбивать руками, ошибиться нельзя | Сборка строит формы через татвиль по типу соединения, «несуществующая» форма (دـ) идёт дистрактором |
| Мягкая проверка транскрипции | Не наказываем за отсутствие макрона и точки под буквой | `з̱а̄да` = `зада` = `zada` = `dhada`; одна опечатка в слове от 4 букв засчитывается с подсказкой точной записи |
| Ошибка возвращается в конце урока | Урок закрывается только когда всё решено верно, точность считается по первой попытке | Очередь шагов в `lesson-player.tsx` |
| Клавиатура везде | Урок проходится без мыши | 1–9 выбор/плитки, Backspace убрать плитку, Enter проверить/дальше, Esc выход с подтверждением; в повторении Пробел и 1–4 |
| FSRS с превью интервалов | Видно, когда карточка вернётся при каждой оценке | ts-fsrs 5.4, `previewDue`; «Снова» возвращает карточку в ту же сессию |
| «Продолжить» одной кнопкой | Ученик не думает, что делать | Если накопилось ≥10 карточек — в повторение, иначе следующий непройденный урок; Enter с главной |
| Стрик по локальной дате, полоса недели, кольцо цели | Мотивация без аккаунта | `sessions` в Dexie, цель 5/10/15/20 мин переключается на главной |
| Книжная тема | Не похоже на типовое «приложение для языков» | Бумага, киноварь для рубрик, синие чернила для действий, арабско-индийские номера юнитов на карте; светлая и тёмная тема без мигания |
| Арабский без обрезанных огласовок | Фатха и дамма не наезжают на строку выше | `lang="ar" dir="rtl"`, line-height 1.8–2, Amiri для крупного текста |
| Звук не ломает урок | Аудио пока нет | Сборка ставит поле `audio`, только если файл лежит в `public/audio/`; иначе кнопки нет |
